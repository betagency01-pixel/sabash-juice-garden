# Sabash Juice Garden

Website for Sabash Juice Garden, Pudupakkam Main Rd, Pudupakkam, Tamil Nadu.

A single-page site (`index.html`) with the full menu, English / Tamil switching and a demo
ordering flow. It is plain HTML, CSS and JavaScript, with no build step.

## Run locally

```
python -m http.server 8770
```

Then open http://localhost:8770/index.html

## Status

- Ordering is a front-end demo only. No orders are sent anywhere.
- Gallery and some menu photos are placeholders: shop photos from Google Maps contributors and
  food photos from Wikimedia Commons (credited in the site footer). Replace them with the shop's
  own photography before treating this as the final site.
- `ai-image-prompts.md` has prompts for generating branded imagery.
